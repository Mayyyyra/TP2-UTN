# Food Store - Sistema de Gestión de Pedidos

Trabajo Práctico Integrador para la materia Programación II.
Sistema de consola desarrollado en Python orientado a la gestión de un negocio de comidas, aplicando los principios de la Programación Orientada a Objetos (POO).

## Requisitos del Sistema

- Python 3.12
- Bibliotecas estándar de Python.

1. Clonar el repositorio o descargar el código fuente.
2. Abrir una terminal y ubicarse en la carpeta raíz del proyecto.
